# AI Adapter — التحريك الذكي (Smart Motion)

> **المرحلة الخامسة — تصميم فقط، غير موصول بعد.** الأداة تعمل بالكامل بدون هذا
> المكوّن. التحريك الذكي **اختياري ومغلق افتراضياً** (البرومبت §12).

## الفكرة الجوهرية

الذكاء الاصطناعي **لا يخترع حركة حرة**. يستقبل وصفاً مجرّداً للأيقونة، ويعيد
**ثلاثة اقتراحات** (مؤسسي / تعليمي / ديناميكي) مبنية **فقط** من مفردات المحرك في
[`vocabulary.json`](vocabulary.json). لذلك كل اقتراح **قابل للتنفيذ فوراً** عبر
نفس محرك الحركة المحلي — لا فجوة بين "فكرة الـ AI" و"ما تستطيع الأداة فعله".

```
تقرير الأيقونة (مجرّد) ─► [System + User prompt + vocabulary] ─► JSON: 3 اقتراحات
        │                                                              │
   من المحلل المحلي                                          ينفّذها محرك الحركة
```

## الخصوصية (البرومبت §12)

يُرسَل فقط **أحد** هذه، وبعد موافقة صريحة من المستخدم:
- تقرير هندسي مجرّد (أعداد/علاقات — لا معنى تجاري)، أو
- SVG مبسّط بلا بيانات وصفية، أو
- صورة معاينة منخفضة الدقة.

**لا يُرسَل أبداً:** ملف مشروع After Effects، أسماء الملفات الداخلية، معلومات
المؤسسة. البرومبت نفسه يمنع النموذج من طلب أو افتراض أيٍّ منها.

## قابلية تبديل المزوّد

الطبقة مصمَّمة حول **عقد نصّي + مخطط JSON** ([`schema/suggestions.schema.json`](schema/suggestions.schema.json))
لا حول مزوّد بعينه. أي مزوّد يقبل system/user ويعيد JSON منظَّماً يصلح. المزوّد
الافتراضي في هذه البيئة هو Claude (نستخدم إخراجاً منظَّماً/أداة لضمان مطابقة
المخطط)، لكن استبداله لا يمسّ بقية الأداة.

## الملفات
- `prompts/smart-motion.system.md` — تعليمات النظام (الدور، القواعد، الخصوصية، صيغة الإخراج).
- `prompts/smart-motion.user.md` — قالب رسالة المستخدم بعناصر `{{...}}` يملؤها المحول.
- `vocabulary.json` — المفردات المسموحة (الحركات، التتابع، Easing، الأنماط، مدى المعاملات).
- `schema/suggestions.schema.json` — مخطط الإخراج الصارم (٣ اقتراحات).
- `examples/gear.output.json` — مثال إخراج لأيقونة "ترس".

## السلوك عند انقطاع الإنترنت (§12)
لا تتعطل الأداة؛ تعرض الحركات المحلية؛ توضح أن التحليل الدلالي غير متاح؛ لا تفقد
إعدادات المستخدم. (يُطبَّق في طبقة المحول عند وصله لاحقاً.)
