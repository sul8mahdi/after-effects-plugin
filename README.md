# Icon M Pro

إضافة مؤسسية لـ **Adobe After Effects 2026** لاستيراد الأيقونات الفيكتورية،
فهم تكوينها، تعديل مظهرها، ثم تحريكها بجودة احترافية.

> **الحالة: المرحلة الأولى (الأساس + محرك الفحص).** التحريك والمظهر والذكاء
> الاصطناعي في مراحل لاحقة — انظر [حالة المشروع](#حالة-المشروع).

---

## المعمارية

طبقتان (القرار التقني الكامل في [`DECISION.md`](DECISION.md)):

| الطبقة | المسار | التقنية |
|---|---|---|
| الواجهة | `client/` | لوحة CEP — HTML/CSS/JS حديث، عربي/إنجليزي، RTL |
| المحرك | `host/` | ExtendScript (ES3 فقط، وفق `CLAUDE.md`) |

الجسر: `CSInterface.evalScript()`. الواجهة تستدعي `IMP.api.*` في المحرك، والمحرك
يعيد **JSON نصياً** فتحلّله الواجهة. المخرجات عناصر After Effects أصلية فقط،
فتعمل على جهاز بلا الإضافة.

```
client/  →  evalScript  →  host/  →  After Effects DOM
```

## التثبيت للتجربة (macOS)

```bash
bash tools/install-macos.sh
```

يفعّل وضع تصحيح CEP (لتحميل إضافة غير موقّعة) ويربط المستودع بمجلد إضافات CEP.
ثم:

1. أعد تشغيل After Effects 2026.
2. `Window > Extensions > Icon M Pro`.

للإلغاء: احذف الرابط الرمزي المذكور في نهاية مخرجات السكربت.

> Windows: لم يُختبر بعد؛ لن نصفه بأنه مدعوم قبل اختباره (وفق معايير القبول).

## التجربة داخل After Effects

1. افتح تركيباً (Composition) وحدّد طبقة **Shape** واحدة أو أكثر.
2. في اللوحة اضغط **«افحص الأيقونة»**.
3. اقرأ التقرير: عدد المسارات، المجموعات، الألوان، السماكات، المسارات الفارغة،
   ومستوى التعقيد، مع أي تنبيهات.

زر التبديل **English/العربية** أعلى اللوحة يغيّر كل النصوص والاتجاه فوراً.

### أداة الفحص العميق (للمطوّر)

`host/lib/logger.jsx` أداة مستقلة: `File > Scripts > Run Script File` مع طبقة
محدّدة، تكتب بنية الطبقة الكاملة (matchNames، الأنواع، القيم، أزمنة المفاتيح) إلى
`logs/inspect.txt`. مفيدة قبل كتابة أي حركة على بنية غير مألوفة.

> يتطلب تفعيل: `Preferences > Scripting & Expressions > Allow Scripts to Write
> Files and Access Network`.

## الاختبارات (خارج After Effects)

```bash
npm test        # أو: node tests/run.js
```

تغطي ما يمكن اختباره بلا AE:

- **i18n** — تطابق مفاتيح العربية/الإنجليزية، تطابق رموز الإدراج `{...}`،
  الإدراج، الرجوع للغة الافتراضية، وقلب الاتجاه.
- **geometryContract** — كل رمز خطأ/تنبيه/تعقيد يصدره المحرك له ترجمة في
  اللغتين، وشكل التقرير يطابق ما ترسمه اللوحة.
- **es3lint** — يمنع أي صياغة ES6+ في `host/` (بعد تجريد التعليقات والنصوص).

الحالة الحالية: **12/12 ناجحة**.

## حالة المشروع

### مكتمل (المرحلة الأولى)
- بنية المشروع بطبقتين (CEP + ExtendScript) قابلة للتوسّع لكل المواصفات.
- واجهة ثنائية اللغة (عربي افتراضي + إنجليزي) مع RTL وتبديل فوري.
- After Effects Bridge (`host/bridge/api.jsx`) بعقد JSON ثابت.
- Geometry Analyzer v1 (قراءة فقط): مسارات/مجموعات/تعبئات/أوتلاين/ألوان/سماكات/
  مسارات فارغة/تعقيد + تنبيهات.
- Logging على الطبقتين + تراجع آمن ونظام وسم (`IMP:`) للتنظيف الانتقائي مستقبلاً.
- اختبارات Node (12) + مثبّت macOS.

### قيد الاختبار (يحتاج تشغيلك داخل AE 2026)
- تحميل اللوحة فعلياً وتشغيل الفحص على 20 أيقونة متنوعة (بوابة قبول المرحلة الأولى).

### لم يبدأ (مراحل لاحقة)
- المظهر (ألوان/سماكات/Line Caps/Joins) — يحتاج matchNames إضافية موثّقة.
- مكتبة الحركات، Easing، المعاينة، القوالب، الذكاء الاصطناعي، مثبّت Windows.

### يحتاج قراراً منك
- **matchNames للتدرجات وLine Caps/Joins**: غير موجودة في قائمة `CLAUDE.md §3`
  الموثّقة. المحرك حالياً **يرصدها كتنبيه** بدل تخمينها. لتفعيل قراءتها،
  شغّل `logger.jsx` على أيقونة فيها تدرّج/أوتلاين والصق الناتج لأضيفها موثّقة.
